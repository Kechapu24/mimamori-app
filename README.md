# mimamori_app

## アプリ概要

mimamori_appは、離れて暮らす高齢者の活動量をスマートフォンで見守るFlutter製モバイルアプリです。  
Android Health Connectと連携して歩数データを取得し、活動量が一定以下の場合に家族（見守る側）へ通知を送る仕組みを実装しています。  
高齢化社会における「さりげない見守り」をテーマに、専門学校の個人開発課題として制作しました。

---

## 主な機能

- **歩数取得**：Android Health Connect APIと連携し、高齢者の1日の歩数をアプリ内に表示
- **招待コード機能**：見守る側が招待コードを発行し、見守られる側（高齢者）の端末で入力することで家族間を紐付け
- **ユーザー認証**：Firebase Authenticationによる新規登録・ログイン・ログアウト機能
- **活動量通知（実装中）**：活動量が一定値を下回った際、高齢者本人と見守る家族の両方にプッシュ通知を送る機能

---

## 使用技術

| 技術 | 用途 |
|------|------|
| Flutter / Dart | フロントエンド・アプリ全体 |
| Firebase Authentication | ユーザー認証 |
| Firebase Firestore | データ保存・家族間の紐付け |
| Android Health Connect | 歩数データの取得 |
| ローカル通知 | 活動量低下時の通知（実装中）|

---

## 開発背景

高齢の親族を持つ立場から、「毎日連絡しなくても元気かどうかわかる手段がほしい」という実体験をもとに企画しました。  
GPSによる位置追跡ではなく、日常の歩数という自然なデータを使うことで、高齢者のプライバシーに配慮した見守りを目指しています。
